# Attendance integration contract — isolated domain only

Owner Lin, independent reviewer Rigel, acceptance Ada. No routes, database bindings, migrations, UI, provider calls or signing persistence are wired. This is NOT an operational attendance feature. Shared archive remains unavailable, not environment-toggleable.

## Functioning domain composition

`workflow.ts` composes authorization, runtime-validated whole-batch dated admin import, scoped provider identity adapters, calendar/summarization, detached snapshot/hash and actual draft PDF rendering. This is callable/testable library code, not a server endpoint. `Actor` must be obtained from existing authenticated server context; permissions are explicit attendance permissions, never arbitrary client role flags. `Scope` must be independently fetched from an active tenant enrollment before any profile/evidence reads. Caller-supplied profile/enrollment data is not independently authoritative; this is an explicit repository dependency, not evidence that spoofed data is safe to certify.

CSV/B4B adapter accepts a normalized cumulative-hours DTO, preserves its cumulative diagnostic only, never assigns a day. xAPI adapter accepts a mapped normalized statement identity/date DTO, returns no duration evidence. Existing parsers/DB ingestion are not wired; an organization/enrollment/course-aware repository must select the mappings and normalize the inspected source models. There is no unsupported actual-hours inference. Manual entry supports one dated authoritative total or independently verified code, verifier from server actor; entire batch validates before caller receives results. No write is persisted here.

Frozen snapshot now includes complete evidence-content digest/revision, versioned proposed P240 rule, explicit unapproved flag, reporting timezone, template version. Hash also binds organization/member/enrollment scope and full provenance. Evidence updates change frozen identity even when source key/hours are unchanged. Snapshot type is internal version 1, not a deployed API contract.

`planSigningTransition` is a side-effect-free reducer for validation/specification: student-first, separate configured authenticated instructor, explicit POST/consent, decisions required, exact hash/revision, superseding signed states. It creates NO signature, archive or authority. A route MUST NOT call this reducer as a substitute for `attendanceProtectedOperations`. All real finalize/student-attest/request-sign/sign/archived-download methods unconditionally throw `ATTENDANCE_VERIFIED_ARCHIVE_UNAVAILABLE`. No boolean/JSON/env flag enables them. Disabled invitation adapter never creates links, messages, tokens, attachments or provider calls.

## Proposed persistence model (not applied or registered with Prisma)

| Record | Minimum columns and constraints |
|---|---|
| attendance_sheet | UUID id; organization/member/enrollment composite FK to verified active enrollment; kind; selected period; Chicago timezone; current revision UUID; created actor/time. Scope identity immutable. Enrollment/subject erasure fence coordinated with retention. |
| attendance_evidence_revision | UUID id; composite scope FK; source identity; date; kind; integer nullable minutes; reference; reason; verifier subject UUID; created server time; content SHA-256; nullable supersedes FK scoped to same evidence. Append-only; old records retained, one authoritative current daily total. Import idempotency key unique per org plus payload hash. |
| attendance_snapshot | UUID revision id; sheet composite FK; version; canonical JSON including profile/enrollment, daily coverage/unknowns, immutable evidence revisions+content digest; rule/timezone/template versions; snapshot SHA-256; created actor/time; immutable. Never update a signed snapshot after source sync. |
| attendance_signing_request | UUID id; scoped snapshot FK; configured instructor subject UUID and configuration version; student attestation actor/time/hash; instructor decisions; status; monotonic revision; idempotency key+payload digest unique per request/actor/action; server expiry; server CSRF/origin enforcement. GET navigation has no writes. |
| attendance_artifact | UUID id; scoped snapshot/request FK; generated archive UUID path; private bucket; immutable bytes SHA-256 and size; signature-reference revision plus explicit signer/time/consent; supersedes/void reason and actor via append-only event. No public URL. |
| attendance_operation | Subject-scoped erasure/concurrency fence; unique operation key and payload digest; pending/committed/ambiguous outcome; staged artifact UUID; reconciliation metadata without sensitive content in logs. |

Proposed schema enforcement: CHECK valid kinds/states/minutes/hash lengths; composite FKs prevent cross-tenant refs, uniqueness for immutable revision and idempotency identities; server-only tables with RLS enabled and revoked anon/authenticated/service_role direct table access consistent with application DB pattern; triggers prohibit update/delete of snapshots/evidence/artifacts. Scoped transaction verifies active tenant/subject and locks sheet+subject operation fence, validates current revision/hash, records consent and archive metadata atomically. Archive upload cannot share SQL transaction: stage unique object with no-overwrite, verify reread bytes, then commit metadata; failed/ambiguous outcomes quarantined for reconciliation, cleanup only owned staged UUID, never signed historical artifacts. No deployed DDL or transaction implementation claimed.
