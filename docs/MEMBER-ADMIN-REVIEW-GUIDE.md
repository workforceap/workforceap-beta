# Reviewing J5 and finding member tools

## Review or download a J5

1. Open **Admin → Members**, select the member, then open **J5 / J6 billing**.
2. In the J5 section, choose **View J5 PDF** to review the saved document on screen.
   **Open J5 PDF in a new tab** is also available if the embedded preview is inconvenient.
3. Choose **Download J5 draft PDF** to save an unsigned review copy. Reviewing or
   downloading does not sign the document, send email, or submit it to anyone.
4. If the data needs a correction, edit and save a new draft, then review it again.
5. Once the designated signer has explicitly approved and signed the document,
   **Download signed J5 PDF** saves the archived signed version for manual delivery.

If no saved draft exists, record the J5 readiness information and save the draft first.
Signature and delivery requirements still apply to their own actions. They do not
prevent an authorized admin from reviewing an existing draft PDF.

## AI Career Tools

Members can find **AI Career Tools** on their home page and near the beginning of
the mobile navigation. The home introduction keeps a suggested tool visible and
offers access to the full tool collection even when no personalized suggestion exists.

The tools page offers direct starts for a resume, interview preparation, and a cover
letter, with short instructions: choose a task, provide the requested details, and
review or refine the result. Members should check generated content before using it.

## Workspace email

The admin workspace currently cannot create real mailboxes. A saved
`@workforceap.org` address is not proof that a mailbox exists. An email administrator
must create the mailbox with the organization's email host and privately provide
the member's sign-in link and invitation or temporary password. WorkforceAP portal
access does not automatically provide mailbox access.

See [workspace email](WORKSPACE_EMAIL.md) for implementation status and
[billing packets](BILLING-PACKETS.md) for document date and archive rules.
